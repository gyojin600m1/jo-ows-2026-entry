# 第49回 JOCジュニアオリンピックカップ 夏季水泳競技大会 OWS競技 エントリー確認

- 日本水泳連盟「スタートリスト」（2026-10-01 公開）をもとにした、非公式のエントリー確認アプリです。
- 211名・235件（男子10km 14 / 女子10km 3 / 男子7.5km 36 / 女子7.5km 26 / 男子5km 85 / 女子5km 71）。
- スタートリストは画像のPDFのため、目で読み取って `data.tsv` に入力しています。
- `python3 build.py` で `template.html` と `data.tsv` から `index.html` を作り直します。
- 公開は `jo-ows-2026-entry` リポジトリの `gh-pages` ブランチから行います（`index.html` だけあれば動きます）。
